# n8n on Miabi: queue mode, via GitOps

`miabi.io/v1` manifests for a Miabi GitOps source (branch `main`, path `n8n`). Every `.yaml`/`.yml`
file in this directory is parsed as a manifest, so keep Compose files and other YAML out of it.

| File | Declares |
|---|---|
| `stack.yaml` | Stack `n8n`, plus the public-hostname variables (filled in after the first sync) |
| `secrets.yaml` | `n8n-encryption-key`, `n8n-runners-auth-token`, generated by Miabi and never in Git |
| `databases.yaml` | Managed PostgreSQL 17 `n8n-postgres` and Redis 8 `n8n-redis` |
| `apps.yaml` | Volume `n8n-data`; apps `n8n`, `n8n-worker`, `n8n-runners` (n8n 2.48.4) |

| App | Role | Strategy | Health check |
|---|---|---|---|
| `n8n` | Editor, API, triggers, webhooks; the only public app | recreate | HTTP `/healthz` :5678, 120 s start period |
| `n8n-worker` | Runs every execution | rolling | HTTP `/healthz` :5678 |
| `n8n-runners` | Code-node sandbox for the worker | rolling | image default |

Database credentials and the two secrets reach the apps as vault references, resolved at each
deploy. Nothing sensitive is stored in this repository.

## First sync

1. **Clean up first.** If you imported the earlier Compose version in the console, delete that
   stack and its five apps, so GitOps creates its own. Uppercase vault secrets created for the
   Compose version (`N8N_ENCRYPTION_KEY`, `N8N_DB_PASSWORD`, `N8N_RUNNERS_AUTH_TOKEN`) are no longer
   used.
2. **Set the timezone.** Edit `UTC` in `apps.yaml` (`GENERIC_TIMEZONE` and `TZ`, on `n8n` and
   `n8n-worker`) if you want another.
3. **Push, then sync.** Use **Sync now**; an `auto` source picks it up within three minutes. The
   source's diff view previews the plan first. Miabi applies in dependency order: secrets and
   volume, then stack and databases, then the apps.
4. **If `n8n-worker` fails its first deploy,** it probably started before `n8n` finished the
   database migrations. Redeploy it once `n8n` is healthy.
5. **Set the public hostname.** Open `n8n → Network → External access` and copy the generated
   hostname (`<label>.<MIABI_EXTERNAL_BASE_DOMAIN>`). In `stack.yaml`, uncomment the `env:` block,
   put the hostname in all three values, then push and sync again. Every member is redeployed with
   it.
6. **Create the owner account** at `https://<hostname>/`. Then run a workflow with a Code node: it
   should succeed, and `n8n-worker`'s Logs tab should show the execution.
7. **Back up the encryption key.** Reveal `n8n-encryption-key` in the vault (Admin) and store a
   copy outside Miabi.

Until step 5, the editor works at the generated URL and webhooks are received. But n8n builds every
other URL itself, and those point at `localhost`: webhook URLs shown in nodes, Wait and "send and
wait" resume links, OAuth2 callbacks, and invite and password-reset emails.

## Running it

- **Changes go through Git.** Console edits to these apps are reverted by the next sync, and source
  changes are refused (`409`). Redeploying and viewing logs from the console are fine.
- **Upgrades:** bump `tag` on all three apps in one commit, since the runners image must match n8n.
  Rollback restores the image only, and n8n migrations aren't reversible, so back up `n8n-postgres`
  from the Databases page before each upgrade.
- **The hostname** stays with the app through redeploys and renames. It changes if the cluster's
  base domain changes or the app moves location: update `stack.yaml`, push, and re-register
  webhooks with third parties.
- **Prune:** if you enable it on the source, deleting a manifest deletes the resource. For a
  database, that includes its data.
- **Never rotate `n8n-encryption-key`.** Every saved credential would become unreadable.
- **Scaling:** don't add `n8n-worker` replicas, because the runner pairs with one worker. Add a
  second worker + runners pair, or raise the worker's concurrency.
- **Same node:** apps reach the databases and each other by name. That needs one node, or a location
  that runs a swarm.
- **Editor shows "Connection lost":** if the gateway isn't passing websockets, add
  `N8N_PUSH_BACKEND: sse` to `n8n`'s env.
